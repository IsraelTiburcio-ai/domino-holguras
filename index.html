Cuatro relaciones que encajan

sᵢ > 0 → yᵢ = 0Sobra recurso → precio sombra cero.

yᵢ > 0 → sᵢ = 0Precio sombra positivo → restricción primal activa.

xⱼ > 0 → tⱼ = 0Variable primal positiva → restricción dual activa.

tⱼ > 0 → xⱼ = 0Holgura dual positiva → variable primal cero.

Cero no implica positividad: sᵢ = 0 no obliga a yᵢ > 0, ni tⱼ = 0 obliga a xⱼ > 0.

La regla detrás de las fichas

Primal: max cᵀx, Ax ≤ b, x ≥ 0.
Dual: min bᵀy, Aᵀy ≥ c, y ≥ 0.

sᵢ = bᵢ − (Ax)ᵢ · tⱼ = (Aᵀy)ⱼ − cⱼ.
En un par óptimo factible: sᵢyᵢ = 0 y xⱼtⱼ = 0.

Activa significa holgura cero. Los índices siempre se corresponden. El precio sombra se refiere a la variable dual de esa solución; no se afirma un cambio de beneficio para perturbaciones arbitrarias.
